CO₂-måler til klasseværelser
Dette projekt viser, hvordan man kan udvikle en CO₂-overvågningsløsning til klasseværelser. Hvis CO₂-niveauet overstiger 1000 ppm (den lovbestemte grænse), får brugeren en besked om at lufte ud.

Teknologier brugt:

Frontend: HTML, CSS, Vue.js og JavaScript

Backend: REST API med tilkoblet bibliotek (library-klasse) til datamodeller og logik

Hardware: Raspberry Pi til måling af CO₂

Proxy-kommunikation: Raspberry Pi sender målinger til API’et via proxy

Formålet er at skabe en praktisk og sikker løsning, der kombinerer hardware og software for at forbedre indeklimaet i undervisningsmiljøer.
